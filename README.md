# Elevate Labs - Web Development Internship: Task 1

## Responsive Landing Page
A simple, clean, and fully responsive landing page built using HTML5 and CSS3.

### Features
- Semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<footer>`)
- Flexible Flexbox layouts for modern spacing
- Media queries for desktop, tablet, and mobile responsiveness
- Social media icon links in footer

### Tools Used
- Visual Studio Code
- Chrome Browser & DevTools
- Live Server Extension
